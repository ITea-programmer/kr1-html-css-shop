# ВышRead — учебный интернет-магазин

## Описание

Проект представляет собой многостраничный сайт книжного интернет-магазина
«ВышRead» — магазина учебников по высшей математике. Проект выполняется
в рамках дисциплины «Фронтенд и бэкенд разработка».

## Тема контрольной работы №1

«HTML и CSS: разработка многостраничного сайта».

## Используемые технологии

- HTML5;
- CSS3 (Flexbox, Grid, CSS-переменные);
- JavaScript (ES6);
- БЭМ-методология;
- Git и GitHub.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Самостоятельные доработки (Практическая работа №8)

В рамках практической работы №8 были выполнены следующие самостоятельные
доработки проекта.

### 1. Добавление собственных страниц, разделов и компонентов

- Создана страница **`product.html`** — подробная карточка книги
  (с обложкой, описанием, ценой и таблицей характеристик).
- Создана страница **`order.html`** — оформление заказа
  (форма с полями: ФИО, e-mail, телефон, книга, количество, способ доставки,
  адрес, комментарий, согласие на обработку данных).
- На странице `product.html` добавлен блок **«Похожие книги»** — три карточки
  с рекомендациями.
- На странице `product.html` добавлена **таблица характеристик книги**
  (автор, название, раздел, издательство, год, ISBN, страниц, переплёт,
  уровень, наличие).

### 2. Добавление дополнительных карточек товаров

- Каталог расширен с **3 до 10 книг** по разделам высшей математики:
  математический анализ, линейная алгебра, теория вероятностей,
  дискретная математика, численные методы, дифференциальные уравнения,
  функциональный анализ.
- Все книги — реальные классические учебники: Демидович, Фихтенгольц,
  Смирнов, Гельфанд, Ильин и Позняк, Гнеденко, Новиков, Самарский,
  Арнольд, Колмогоров и Фомин.

### 3. Улучшение навигации и структуры страниц

- Добавлены ссылки **«Карточка книги»** и **«Оформить заказ»** во все меню
  сайта — единая навигация на всех 5 страницах.
- Добавлены **хлебные крошки** на внутренних страницах
  (`catalog.html`, `product.html`, `order.html`, `contacts.html`).
- Добавлены **фильтры в каталоге**: по разделам математики (6 категорий)
  и по цене (от/до).
- Реализована **подстановка книги по параметру `?id=` из URL** —
  ссылки в каталоге ведут на `product.html?id=<book>`, и карточка
  открывается с данными выбранной книги.
- Реализована **автоподстановка книги** в форме заказа по `?id=` —
  при переходе с карточки на заказ книга уже выбрана в `<select>`.

### 4. Разработка собственного визуального оформления

- Разработан **фирменный стиль магазина «ВышRead»** — логотип
  с акцентным цветом «Read».
- Добавлены **обложки книг** (папка `images/books/`) — 10 изображений.
- Добавлена **кнопка «Наверх»** (`position: fixed`) на всех страницах.
- Добавлены **hover-эффекты** карточек, кнопок и ссылок.
- Добавлены **тени** для карточек, обложек и кнопки «Наверх».
- Разработаны **градиентные обложки** как запасной вариант оформления
  (CSS-градиенты по разделам математики).

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `catalog-products` — список товаров в каталоге;
- `filters-form` — форма фильтров;
- `product-detail` — карточка книги на странице product.html;
- `product-table` — таблица характеристик;
- `book-cover-image` — обложка книги;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `order-page` — страница оформления заказа;
- `button` — кнопка;
- `scroll-top` — кнопка «Наверх»;
- `success-message` — сообщение об успешной отправке;
- `aside-info` — информационный блок;
- `site-footer` — подвал сайта.
